# Instagram Galeri — Kullanım

## Görsel ekleme (kolay yol)

1. Admin → **Instagram Galeri** → **Yeni görsel ekle**
2. **Dosya seç** ile telefon/bilgisayardan fotoğraf yükleyin
3. İsterseniz Instagram post linkini “tıklanınca gidilecek link” alanına yapıştırın
4. **Galeriye ekle**

## Instagram gönderi linki ile (URL kopyalamadan)

1. Instagram uygulamasında veya sitede gönderiyi açın
2. **Paylaş → Bağlantıyı kopyala**
3. Admin panelde **Instagram gönderi linki** alanına yapıştırın
4. **Galeriye ekle** — modül görseli otomatik indirir

> Gönderi **herkese açık** olmalıdır. Kapalı hesap / özel gönderilerde çalışmayabilir.

## Dosya yolu

Yüklenen görseller: `modules/instagram-gallery/assets/img/`

Veritabanında `local:dosya.jpg` olarak saklanır; sitede otomatik tam URL’ye çevrilir.
